# Contributing to obserae

Thanks for your interest in obserae.

## Code contributions

**obserae does not accept code contributions.** The source is proprietary and
published by a single vendor; keeping it single-owner is deliberate — it keeps
the intellectual property clean and the project's direction coherent. Pull
requests are closed with a pointer to this page; please don't take it personally.

## Issues are very welcome

Bug reports, reproduction cases and feature suggestions genuinely help. Please
send them to <support@spartan-conseil.fr>.

## Source access & licensing

Qualified reviewers can request source access for security review, and the common
questions about who pays, telemetry and how the terms can change are answered in
[Licensing & transparency](LICENSING.md).
